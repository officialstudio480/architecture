# ARCHI SUPPORT v1.1

建築学生向けのサポートサイト。

## 今回の変更

- サイト内検索を追加
- 「コンクリート / 木材 / 石 / タイル / 金属 / ガラス」の素材カテゴリを追加
- 法令を「用途・地域 / 面積・規模 / 採光・換気 / 避難・安全 / 防火・消防 / 都市計画・高さ」に分類
- 法令ジャンルを押すだけで、そのジャンルの項目を一覧表示
- カテゴリボタンを押すだけで検索できるように改善
- ヘッダーにSEARCHを直接表示
- PCでは「縮尺計算 / 建築計算 / 法令検索 / 素材検索 / SEARCH / ABOUT」を直接選択可能
- スマートフォンではハンバーガーメニューに切り替え
- サイト内検索からツール・法令・素材を横断検索
- 法令や素材の検索結果から、それぞれの検索ページへ直接移動
- `law.html?q=採光` のように検索語を渡すと、法令検索ページでその語を自動入力
- `materials.html?q=木材` のように検索語を渡すと、素材検索ページでその語を自動入力
- 既存の縮尺計算・建築計算・法令検索・素材検索・ABOUTの機能は維持

## ファイル

- index.html：トップページ
- style.css：全ページ共通デザイン
- script.js：共通JavaScript
- scale.html：縮尺計算
- calculator.html：建築計算
- law.html：法令検索
- materials.html：素材検索
- search.html：サイト内検索
- about.html：ABOUT
- EDIT_GUIDE.md：編集方法

## 検索データを増やす

`search.html` の `const items = [...]` に項目を追加できます。

例：

{
  title: "新しい項目",
  category: "法令",
  keywords: "検索に使うキーワード",
  description: "項目の説明",
  url: "law.html?q=新しい項目"
}


## v1.2で追加した機能
- 法令の各項目からGoogle検索へ移動できます。
- 素材の各項目からGoogle検索へ移動できます。
- サイト内検索の各結果からGoogle検索へ移動できます。
- `script.js` の `openGoogleSearch()` が共通のGoogle検索処理です。


## v1.3
法令ページを、項目ごとにGoogle検索へ移動できる方式に統一しました。
各法令データの `q` を変更すると、その項目のGoogle検索ワードを簡単に変更できます。


## v1.4
- 素材の各項目からGoogle検索へ移動
- 建築計算の各項目からGoogle検索へ移動
- 各ボタンは項目に合わせた検索ワードを使用


## v2.1 計算機の注意
採光・日影は簡易計算、建ぺい率・容積率は入力値からの単純な割合、階段は用途別の代表基準値との比較です。法令適合判定を代替しません。法令情報は最新の公的資料で確認してください。
